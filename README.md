# نظام إدارة المهام - دليل الاستخدام والاختبار

## نظرة عامة
نظام إدارة مهام شامل يدعم الأدوار المختلفة (مدير، مصمم، معمل، محاسب) مع فلترة متقدمة حسب الصلاحيات.

## 🚀 النظام الجديد - سهل الاستخدام

### ✨ الميزات الجديدة
- 🎯 **واجهة سهلة الاستخدام**: إعدادات الفلترة بخطوات بسيطة
- 📁 **تخزين JSON**: لا حاجة لتعديل قاعدة البيانات
- 🔄 **نظام موحد**: اتصال قاعدة بيانات موحد وآمن
- ⚡ **أداء محسن**: فلترة سريعة وفعالة
- 🔧 **سهولة الصيانة**: كود منظم ومُوثق

### 🎛️ كيفية الاستخدام

#### 1. الوصول لواجهة الإعدادات
```
http://localhost/new_injaz/src/View/settings/role_filters_new.php
```

#### 2. خطوات الإعداد
1. **اختر الموظف**: حدد الموظف المطلوب تخصيص إعداداته
2. **اختر الصفحة**: حدد الصفحة (لوحة التحكم، الطلبات، التقارير)
3. **حدد نطاق العرض**: اختر من يرى المهام (جميع المهام، مهام الدور، مهامه الخاصة)
4. **فلاتر تخصيصية**: حدد الحالات المطلوب عرضها أو إخفاؤها

#### 3. حفظ الإعدادات
- الإعدادات تُحفظ في ملف `employee_filter_settings_new.json`
- لا حاجة لإعادة تشغيل الخادم
- الإعدادات تطبق فوراً

## إعدادات الفلترة

### ملف `employee_filter_settings_new.json`
يحتوي على إعدادات الفلترة لكل موظف وسياق:

```json
{
    "employees": {
        "1": {
            "name": "المدير العام",
            "role": "مدير",
            "settings": {
                "dashboard": {
                    "view_scope": "all",
                    "show_stages": [],
                    "hide_stages": [],
                    "exclude_combinations": [
                        {
                            "status": "مكتمل",
                            "payment_status": "مدفوع"
                        }
                    ]
                }
            }
        }
    }
}
```

### أنواع الفلاتر
- **show_stages**: عرض المهام في الحالات المحددة
- **hide_stages**: إخفاء المهام في الحالات المحددة
- **exclude_combinations**: استبعاد المهام التي تحقق شروط مركبة

### نطاقات العرض
- **all**: عرض جميع المهام
- **role**: عرض مهام جميع موظفي نفس الدور
- **self**: عرض المهام الخاصة بالمستخدم

## دليل الاستخدام

### للمدير
- يرى جميع المهام في جميع السياقات
- في الداشبورد: لا يرى المهام المكتملة والمدفوعة معًا
- في الطلبات: يرى جميع المهام

### للمصمم
- يرى مهام "قيد التصميم" من دوره
- يمكنه تحديث حالة المهام

### للمعمل
- يرى مهام "قيد التنفيذ" و "جاهز للتسليم" من دوره
- يمكنه تحديث حالة المهام

### للمحاسب
- يرى مهام "تأكيد استلام العميل" و "مكتمل" من مهامه
- يمكنه تحديث حالة الدفع

## استكشاف الأخطاء

### مشاكل شائعة

#### 1. عدم ظهور المهام
- تحقق من إعدادات `employee_filter_settings_new.json`
- تأكد من أن الدور مفعل
- تحقق من نطاق العرض (`view_scope`)

#### 2. ظهور مهام غير مرغوبة
- راجع إعدادات `show_stages` و `hide_stages`
- تحقق من `exclude_combinations`

#### 3. أخطاء في الاتصال بقاعدة البيانات
- تحقق من ملف `src/Bootstrap.php`
- تأكد من صحة إعدادات قاعدة البيانات
- راجع ملف `.env` إذا كان موجوداً

tail -f /path/to/php/error_log

## التطوير والصيانة

### إضافة دور جديد
1. أضف الدور في `employee_filter_settings_new.json`
2. حدث `RoleBasedQuery::getAvailableRoles()`
3. أضف منطق خاص في `buildRoleBasedConditions()` إذا لزم الأمر

### إضافة سياق جديد
1. أضف السياق في `employee_filter_settings_new.json`
2. حدث استدعاءات `buildRoleBasedConditions()` لتمرير السياق الجديد

### تحسين الأداء
- استخدم فهرسة قاعدة البيانات
- راجع استعلامات SQL للتحسين
- استخدم التخزين المؤقت عند الإمكان
