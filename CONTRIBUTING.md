# Contributing

Guidelines for contributing to this project.

- Create a new branch from `main` named `feature/your-feature-name` or `fix/your-fix-name`.
- Run unit tests before pushing: `php ./vendor/bin/phpunit tests`.
- Add tests for new behavior.
- Open a Pull Request describing the change, linking issues and test evidence.

Code style: keep existing formatting. Add static analysis (PHPStan/Psalm) in a follow-up PR.
